# Portal

Read this only for a Maestri embedded browser portal.

List portal names first. Snapshot the selected portal to obtain a fresh accessibility tree and refs; use refs in preference to coordinates or stale selectors. After navigation, click, fill, key, or selection action, take a fresh snapshot to verify the state. A popup is a newly listed portal target and must be resolved by name.

Do not evaluate arbitrary page script, extract cookies/tokens, bypass access controls, or submit a sensitive/destructive form without explicit authorization. Use a screenshot only for visual layout confirmation; use the snapshot for interaction state.
