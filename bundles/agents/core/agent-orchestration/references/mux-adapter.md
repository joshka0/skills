# Mux Adapter

Use this optional reference only after a dispatch mode is selected and the user explicitly requests a terminal multiplexer such as Zellij or tmux.

Discover the installed transport and its current help before selecting a session, pane, status signal, or launch method. Use its documented literal-input method rather than interpolating a packet through a shell. Keep agent prompts as bounded packets, retain a supervisor-visible completion signal, and use isolated work surfaces or file-disjoint scopes for concurrent mutation.

When continued agent context is materially useful, preserve the live-discovered persistent session and inject only the new bounded revision, feedback, or decision delta. Keep a supervisor-readable result artifact and completion state outside terminal scrollback; if continuation cannot be verified live, return the uncertainty rather than pretending context survives.

Do not encode model names, fixed flags, JSON event schemas, pane keystrokes, screen-dump patterns, fixed filesystem locations, or cleanup commands. Those are version- and environment-sensitive; inspect live capability or report uncertainty. For Herdr or Maestri private transport, hand off to their private-tool skill instead of translating its commands here.
