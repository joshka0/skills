# TDD

Use this mode only for an explicit test-first request.

1. Name the next observable behavior.
2. Write one failing test through the appropriate public seam.
3. Implement only enough behavior to make that test pass.
4. Repeat one behavior at a time.
5. Refactor after the relevant tests are green.

For a non-trivial public-interface change, confirm the behavior and test boundary when the request leaves either materially open.
