# Collaborate

Use this mode when a live decision needs evidence from independent agents rather than a single implementation handoff.

Name only the roles the decision needs: supervisor, context investigator, implementer or drafter, reviewer, adversarial reviewer, verifier, and synthesizer. Give each participant a bounded question, evidence expectation, and report destination. Keep a lightweight live decision record with the question, owner, claims and evidence, dissent, current decision, validation, and next action.

Let independent passes finish before sharing an emerging answer unless cross-review is deliberate. A non-trivial convergence requires a reviewer or adversarial reviewer who did not author the proposal. The synthesizer separates agreed facts, unresolved dissent, decision rationale, and residual risk; the supervisor decides whether to act, request another pass, or hand off a durable lifecycle to `goal-protocol`.

If private message or pane transport is required, use the `herdr` or `maestri` skill to discover targets and send safely. This mode owns the collaboration contract, not those private command surfaces.
