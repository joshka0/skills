## Count method

The campaign rail forbids Git commands. File counts therefore use the
repository's non-ignored regular-file set:

```text
rg --files --hidden -g '!.git/**'
```

At Phase 5 entry, Phase 4 had been orchestrator-reviewed and committed. A
separate physical-file inventory differed from this set by exactly one ignored
`.DS_Store`, so the method captures the commit-candidate tracked estate without
counting Git metadata or ignored host debris. The same method is used before
and after.
