# Goal convergence

Clarify the desired outcome, constraints, horizon, current evidence, and what
would make the goal worth pursuing. Compare alternatives only where the choice
matters. Preserve material disagreement and name the smallest useful experiment
when evidence is missing.

The resulting goal needs a measurable outcome, acceptance evidence, non-goals,
a first useful milestone, and a review or exit condition. Avoid artificial
scores, forced alternative counts, or a mandatory review campaign.

On later review, compare actual progress with the goal. Record a changed
decision without erasing the prior rationale. Ask for approval only where the
user retained that decision.
