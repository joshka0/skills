# Build

Use this mode for a new or redesigned production interface, not an experiment of competing variants.

1. Name the user, task, primary action, and one visual or behavioral differentiator before choosing components or effects.
2. Choose a clear direction that fits the product: calm, native, editorial, playful, or bold can each be distinctive when intentional.
3. Establish hierarchy with composition, type, spacing, and semantic color. Do not default to repeated card grids, decorative metrics, glowing gradients, or glass effects without a content reason.
4. Use the existing token and component system where it fits; make real content, empty, loading, error, and success states carry the design rather than a happy-path mockup.
5. Test the intended flow at the relevant viewport and input method before calling the surface production-ready.
