# Sustained campaigns

Use durable packets and reports when a requested crew campaign spans sessions
or workstreams. Reuse the governing goal ledger or collaboration record; do not
create competing state stores.

Give each agent its source artifacts, scope, evidence requirements, and report
destination. If automation consumes a verdict, define its exact terminal line
in the brief. Accept only completed evidence, not a partial report or screen guess.

Use `herdr-watcher` for supported continuation or join operations. For another
surface, use its documented completion signal. An automated next step must stay
within existing authority; observing success does not authorize publication,
deployment, or a new external action.

Apply the campaign's required independent review gate. Fix substantiated blockers
and rerun affected checks; reopen a finding with evidence when it is wrong.
Do not invent extra roles, pass counts, or mandatory reviews for ordinary work.

At close, reconcile accepted results and preserve material reports and unique
work before authorized cleanup. Verify merge and workspace state directly.
Keep branches and history. Write agent memory only when explicitly requested.
